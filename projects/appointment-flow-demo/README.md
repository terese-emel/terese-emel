# Appointment Flow Demo

A small fullstack TypeScript example showing a healthcare-style appointment flow. It focuses on predictable user interactions, clear API contracts and testable frontend behaviour.

## Demonstrates

- React and TypeScript UI for searching available appointment slots
- Node.js service endpoint for creating an appointment
- Request validation and explicit error states
- Accessible form labels, keyboard-friendly controls and loading states
- Separation between UI state, API calls and domain types

## Why it belongs in this portfolio

This project represents the kind of cross-layer work I enjoy: turning a user workflow into a reliable interface, connecting it to service logic and covering the important edge cases.
